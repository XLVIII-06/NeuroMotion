本图配套固件目标：NeuroMotion_4CH_Right。固件尚未下载时，不按新图上电验证。

右侧DRDY方案，仅移三根MCU端线：A的j1从PA0改PB8（CN10-3/D15）；B的j15从PA1改PB2（CN10-22）；START公共排f13从PB8改PB4（CN10-27/D5）。模块端和其余线路不变。PB8已成为DRDY输入，不能再接START。

当前模式：全部断电，只定位两块板。下方 B 是疑似烧损板，全部电源和信号线均不接。

本轮名称：上方为A、下方为B，不与此前“原A/原B”身份混用。两板针序已由用户确认与V1.1资料一致；旧1mV电阻网络已移出此板。USB与外部电源都关闭后再搬板；模块正面朝上，左排顶针RLDOUT放c1/c15，右排顶针DRDY放g1/g15，向下逐行排列。PCB不必贴平面包板，不强压。

c至g跨距15.24mm，与本地尺寸图600mil一致；a–e同行相通，f–j同行相通，中沟两边不相通。模块会遮住部分孔，实际外接优先用a列和j列；图表同时列出模块针脚孔与外接孔。每孔只插一个端头。

当前只摆板、全部断电；不要按参考表一次接齐疑似烧损B。

点击接线表某一行可突出显示。图线只表示两端关系，交叉处不连接；实际跳线沿板外侧整理。

分步搬迁与检查

  1. 当前只做：全部断电，清除本板遗留跳线、旧电源线和电阻；按c/g列装好两板。疑似B仅摆放，无任何外接线。
  2. 疑似B：全部电源与信号线保持断开，先直流电压档确认b23对b22近0V，再用电阻档红b23（3V3）、黑b22（GND）记录初始和约15秒后读数，观察可见烧痕。没有短路不代表正常；普通电源不能直接作为疑似烧损板的试机电源。
  3. 先验供电分线：模块A/B的电源和数字线均不接时，接PSU_3V3至a11、PSU_GND至a13，核对红e11黑e13确为正3.3V，再关闭电源。此步骤须在定位与B断电检查确认后进行。
  4. A单板：用模式2接A与公共线，B保持完全隔离。断电核线；恢复电源后复位，检查A的ID。四通道固件在B缺席时不启动采样，这是预期，不因此直接重烧固件。
  5. 双板：只有B已被适当验证，或换上未受损并经单板检查的备份件后，才按模式3补接B。首次只检查数字采集、模块ID和错误计数，不接动物/模拟测试网络。
  6. 数字采集稳定后才恢复1mV网络及幅值验证。疑似烧损板若无合适限流条件，只保留隔离检查，不能通过普通3.3V电源直接试机。

检查孔预留：电源排e11(+)/e13(GND)；A供电b9(+)/b8(GND)；B供电b23(+)/b22(GND)。这些孔在工作参考接线中也未被占用。本图不包含临时限流试验电路，不可据此给烧损板直接上电。
